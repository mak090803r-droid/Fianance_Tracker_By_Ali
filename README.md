ALI'S FINANCE TRACKER — INSTALL AND OPEN

INSTALL THE APP
1. Open the setups_outputs folder in this project.
2. Double-click Ali-Finance-Tracker-0.1.0-Setup.exe.
3. Follow the installer prompts. Windows may ask you to confirm that you
   want to run the app; choose the option to continue if you trust this copy.
4. After installation, open Ali's Finance Tracker from the Start menu.

OPEN WITHOUT INSTALLING
You can run setups_outputs\Ali-Finance-Tracker.exe directly by double-clicking
it. Keep the file in a folder you can find again. The installer is the easier
option for normal use.

YOUR DATA
The app stores its finance data locally in your Windows user profile. Use the
app's Settings > Data & backups page to make a backup, and keep a copy somewhere
other than this computer if you want protection from computer or disk failure.

WHERE THE CODE IS
The application code is in the app folder:
- app\src contains the TypeScript user interface.
- app\src-tauri contains the Rust desktop and database code.

This app is not written in Python. A .py file contains Python instructions and
is usually a developer script or tool. The .py files in the work folder are
development/build helper scripts and are not needed to install or run the app.
