# Ali's Finance Tracker

A private Windows app for tracking income, spending, recurring payments, and savings in PKR. Created by **Muhammad Ali Khan**.

## Files

- App source code: [`app/`](app/)
  - User interface: [`app/src/`](app/src/)
  - Rust desktop and database code: [`app/src-tauri/`](app/src-tauri/)
  - This app is **not written in Python**.
- Ready-to-run app: [`outputs/Ali-Finance-Tracker.exe`](outputs/Ali-Finance-Tracker.exe)
- Windows installer: [`outputs/Ali-Finance-Tracker-0.1.0-Setup.exe`](outputs/Ali-Finance-Tracker-0.1.0-Setup.exe)

For usage and build instructions, see [`app/README.md`](app/README.md).
